## Recon

```bash
# host discovery on the lab segment
sudo arp-scan -I vmnet1 --localnet
```

```bash
# full TCP port sweep
nmap -p- --open -sS --min-rate 5000 -n -Pn <TARGET_IP> -oG allPorts
```

```bash
# service and version detection on the open ports
nmap -sVC -p <PORTS> <TARGET_IP> -oN targeted
```
